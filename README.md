# Banki.shop

Тестовое задание — каталог интернет-магазина по [макету в Figma](https://www.figma.com/file/6LxPDEsauEGanhR2nDW68X/Banki.shop?node-id=0%3A1).

## Как запустить

Нужен Node 16 или новее, версия лежит в `.nvmrc`.

```bash
nvm use
npm install
npm run dev
```

Поднимется на http://localhost:5173. Собрать — `npm run build`, посмотреть собранное — `npm run preview`. Ещё есть `type-check`, `lint` и `format`.

## Стек

Vue 2.7 с Composition API и `<script setup>`, TypeScript, Vite, Tailwind.

UI-библиотеки не брал: карточки, модалку, слайдер и иконки написал руками — задание всё-таки про вёрстку, готовые компоненты тут были бы не в тему.

## Где отошёл от ТЗ

Два пункта, и оба сознательно.

**Собираю Vite, а не webpack.** ТЗ просит средство автоматизации сборки — Vite ровно им и является, просто живой. Webpack и gulp в новые проекты сейчас почти никто не тащит: тут TypeScript, PostCSS и code splitting заводятся сразу, конфиг вышел строк на пятнадцать вместо сотни, а дев-сервер стартует меньше чем за секунду и подхватывает правки по HMR мгновенно. На таком объёме это прямая экономия времени, а результат для проверяющего ровно тот же — `npm run build` и статика в `dist/`. Про Node 16 не забыл: взял Vite 4.5, последнюю ветку с его официальной поддержкой, всё гонял на 16.17.0.

**Vue 2.7 и Composition API вместо Options API.** Это по-прежнему Vue 2 — 2.7 последний релиз ветки, в него Composition API и `<script setup>` завезли прямо в ядро, никаких дополнительных плагинов. Взял в основном из-за типов: с `<script setup>` TypeScript выводит всё сам, без `PropType` и обёртки в `defineComponent`, компоненты получились заметно короче и читаются лучше. Плюс логика корзины и поиска нормально вынеслась в композаблы, а не в миксины. Ну и если проект потом поедет на Vue 3 — переписывать почти нечего.

## Что работает

**Поиск** фильтрует карточки прямо во время набора, регистр не важен, ищет по вхождению в название. Если ничего не нашлось, вместо сетки показываю текст.

**Кнопка покупки** проходит три состояния: «Купить» → прелоадер на две секунды → «В корзине» с галочкой. Цвета всех трёх взял из UI-kit в макете. Слово «обрабатывается» в кнопку не влезает — она по макету 118×48, — поэтому на это время кручу спиннер: иначе кнопка прыгала бы в ширину и таскала за собой строку с ценой. Сам текст никуда не делся, лежит в `aria-label` и в тайтле.

**Корзина** хранится в `localStorage`, ключ `banki-shop:cart`. Состояние держу в `useCart.ts` одно на всё приложение, иначе кнопка в карточке и кнопка в модалке разъезжаются. Чтение и запись обёрнуты в `try/catch` — в приватном режиме Safari `localStorage` кидает исключение, и без этого всё просто падает.

**Модалка** открывается по клику на картинку или название: слайдер на три изображения, описание, цена, кнопка покупки. Закрывается крестиком, кликом мимо и по Esc, слайдер листается стрелками. Пока открыта, скролл страницы блокирую.

## Насколько попал в макет

Размеры снимал прямо из Figma, основное сходится: контейнер 1216, карточка 280×328 с шагом 32, картинка 160, кнопка 118×48, поиск 416×48 с кнопкой 122×48, шапка и подвал по 96. Шрифты и палитру забрал из UI-kit.

Дважды отступил намеренно:

- Меню в шапке и подвале в макете начинается на 96px правее сетки карточек, а адрес внизу на 47px вылезает за её правый край — похоже, просто не выровняли. Поставил всё в один контейнер, иначе на других ширинах разъезжается.
- Кнопка «Купить» в каталоге залита `#382E2B`, а в UI-kit — `#403432`. Взял вариант из UI-kit, там состояния кнопки расписаны явно.

«Урок анатомии» в макете полупрозрачная, без кнопки и с «Продана на аукционе» вместо цены — сделал это отдельным флагом у позиции.
